The 3-State File Pipeline

📄

1. Working Directory

Your local disk edits. Git watches, but does not record changes yet.

➔ git add
⚡

2. Staging Area

A holding pen for changes chosen for the next snapshot.

➔ git commit
📦

3. Repository

Permanent snapshot record with parent pointers and SHA IDs.

If you get stuck

Type help in the terminal for the list of commands the simulator understands. git status is never the wrong thing to run — when you are lost, run it and read the hints git gives you. Real git is unusually good at telling you what to do next.
