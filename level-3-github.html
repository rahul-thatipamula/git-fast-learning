Etiquette that is not in the commands

Claim an issue by commenting before you start, so two people do not build the same thing. Keep one pull request to one concern. Write Closes #42 in the description so the issue closes itself on merge. And when a maintainer asks for changes, push more commits to the same branch — the pull request updates itself.
